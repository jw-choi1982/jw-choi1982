# MBTI Saju Website Blueprint

## Overview

This project is a web application that provides users with a "Saju" (Korean fortune-telling) reading based on their MBTI (Myers-Briggs Type Indicator) personality type. The goal is to create a fun and engaging experience for users interested in both MBTI and Saju.

## Features

*   **MBTI Selection:** Users can select their MBTI type from a dropdown list.
*   **Saju Result:** Based on the selected MBTI, the website will display a personalized Saju reading.
*   **Modern UI:** The website will have a clean, modern, and responsive design.

## Project Structure

*   `index.html`: The main HTML file for the application.
*   `style.css`: The stylesheet for the application.
*   `main.js`: The JavaScript file containing the application logic.
*   `blueprint.md`: This file, which documents the project.

## Current Plan

1.  **Create the basic HTML structure (`index.html`)** with a title, description, a dropdown for MBTI selection, a button, and a container for the results.
2.  **Add styling (`style.css`)** to create a visually appealing and user-friendly interface.
3.  **Implement the core logic (`main.js`)** to handle user interaction, map MBTI types to Saju readings, and display the results.
