# 전생코딩 (Past Life Coding)

명리학(사주팔자)의 원리를 현대적인 '코딩' 관점에서 재해석하여, 사용자의 운명 소스코드를 분석해주는 엔터테인먼트 웹사이트입니다.

## 주요 기능
- **운명 디코딩**: 입력된 생년월일시 데이터를 바탕으로 영혼의 로그 파일을 분석합니다.
- **영물 아키타입**: 명리학적 신수(청룡, 백호 등)의 기운을 바탕으로 전생과 현생의 연결고리를 찾아냅니다.
- **세련된 디지털-미스티즘 디자인**: 다크 모드와 골드 포인트, 터미널 느낌의 폰트를 조합한 독특한 UI를 제공합니다.
- **과거/현재/미래 분석**: 단순 전생 풀이를 넘어 영혼의 데이터가 흐르는 전체 타임라인을 제공합니다.

## 기술 스택
- HTML5
- CSS3 (Vanilla CSS)
- JavaScript (Vanilla JS)

## 실행 방법
`index.html` 파일을 브라우저에서 열면 바로 실행됩니다.
