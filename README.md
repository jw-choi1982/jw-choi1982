# 명리전생 (命理前生)

명리학(사주팔자)의 원리를 기반으로 사용자의 전생을 분석해주는 엔터테인먼트 웹사이트입니다.

## 주요 기능
- **사주 기반 분석**: 입력된 생년월일시를 바탕으로 간이 사주팔자를 도출합니다.
- **전생 아키타입**: 오행(목, 화, 토, 금, 수)의 기운에 따라 5가지 전생 아키타입 중 하나를 매핑합니다.
- **감성적인 디자인**: 다크 & 골드 테마와 신비로운 애니메이션을 통해 몰입감을 제공합니다.
- **현생 조언**: 전생의 특징을 바탕으로 현재의 삶에 도움이 되는 조언을 제공합니다.

## 기술 스택
- HTML5
- CSS3 (Vanilla CSS)
- JavaScript (Vanilla JS)

## 실행 방법
`index.html` 파일을 브라우저에서 열면 바로 실행됩니다.
